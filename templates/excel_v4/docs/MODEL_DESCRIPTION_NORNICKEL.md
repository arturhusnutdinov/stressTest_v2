### Экономическая интерпретация

**Норникель** — принципиально здоровая компания. EBITDA margin ~48%, ND/EBITDA < 1x, ковенанты с запасом. Итоговый рейтинг **AAA(RU)** = АКРА (отклонение 0). Стресс severe: EBITDA −40%, но ND/EBITDA ≤ 2x и рейтинг держится A- — «крепость» с низким плечом подтверждается. Делеверидж до 0.7x ниже целевого менеджмента (~1.5x) — следствие консервативного допущения о дивидендах (payout ~33% ΣNI); чувствительность смотреть через CP. PGM-микс (D2): цена сегмента = chain-link 0.72×Pd + 0.28×Pt.
