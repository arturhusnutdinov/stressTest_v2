# КРИТЕРИИ АДЕКВАТНОСТИ ПРОГНОЗА — корпоративная модель (stressTest_v2)

Аналог банковского `bank_model/docs/NEW_BANK_PLAYBOOK.md` §V для корпоративных
моделей (RUSAL, Nornickel, далее — любая компания из Vertex-экспорта).
Механика может быть идеальной, а прогноз — бессмысленным: этот раздел отвечает
на вопрос «верить ли числам». Все критерии измеримы и проверяются скриптом.

**Команда:** `python3 scripts/plausibility_corp.py --company <slug> [--md audit/plausibility_<slug>.md]`
Выход: 0 = PASS, 1 = FAIL. WARN требует записи в MODEL_CARD компании.

---

## V.1 Консистентность с историей

| критерий | порог | комментарий |
|---|---|---|
| Темп выручки 2+ год | полоса истории ±50% ширины | для объёмных метрик проверяется темп, не уровень |
| Темп года 1 | полоса ±15 п.п. | скачок базы/цены года 1 законен (repricing) |
| Маржа EBITDA | история ±10 п.п. | для относительных — уровень, не темп |

## V.2 Экономически допустимые диапазоны (жёсткие)

| метрика | допустимо | смысл |
|---|---|---|
| EBITDA margin | −10 … 55% | металлургия; выше 55% — неустойчиво |
| ROE | −30 … 45% | ниже −30% — разрушение капитала |
| ICR (EBITDA/interest) | ≥ 1.0 (warn < 1.5) | ниже 1 — проценты не покрываются операционно |
| ND/EBITDA | ≤ 8.0 (warn > 4.5) | 4.5 — ковенант; 8 — предел рефинансирования |
| Current ratio | 0.3 … 3.0 | вне диапазона — ликвидность/заморозка |
| Эфф. налог | 10 … 35% (warn) | вне — проверить NOL/деферред |

## V.3 Реакция на макрофакторы

Из `stress_results` (свежий прогон со стрессами). Проверка на первом году.

| сценарий | метрика | знак | разумная величина |
|---|---|---|---|
| lme_mild / demand_shock | EBITDA | − | 5…50% (операционный рычаг) |
| rate_spike | NI | − | 2…80% |
| energy_spike | EBITDA | − | 1…40% |

**Признак дефекта:** EBITDA не реагирует на −20% LME (нет ценового канала) или
растёт (знак сломан). Дополнительно: behavioral-тесты verify_model (монотонность,
операционный рычаг 1–10×).

## V.5 Собственные тенденции

| проверка | порог |
|---|---|
| Скачок EBITDA% г/г | warn >12 п.п., fail >20 п.п. |
| Разворот темпа выручки | ≤ 30 п.п. |
| Смена знака NI | WARN — проверить событие |

## V.6 Замкнутость системы

| критерий | порог | где |
|---|---|---|
| BS identity A−L−E | Δ ≤ $1 все годы | plausibility + engine full_validation + 90_Checks книги |
| CF bridge | = 0 | engine full_validation / книга 90_Checks |
| Corkscrews (PPE/Debt/Equity) | close = open+flows | 90_Checks книги / аудит C |

## V.7 Отсутствие хардкода

| проверка | порог | где |
|---|---|---|
| Литералы в формулах | структурные только (H1 WARN) | audit_corp_model |
| Формулы >300 символов | 0 (известны 2 места: 31_Score!F16:H16 = 608, 90_Checks!F24:H24 = 455) | автотест |
| Источники у макропрогнозов | 100% ячеек с source+tag | 01_Macro кол. J/K |
| Макро-пути flat | 0 (запрещены sanity-fallback пути в base) | macro_forecasts.method |

## V.9 Соответствие бизнес-модели компании

| критерий | порог |
|---|---|
| Доля сегмента в выручке: прогноз vs последний факт | ≤ 10 п.п. (warn ≤ 15) |
| Металлургический класс (EBITDA% / ND-EBITDA) | соответствует отрасли (см. V.2) |
| Потолок мощности (RUSAL 4 100 kt) | объём ≤ nameplate |
| Связка с LME: доля цены в Δвыручки | β ∈ [0.5; 1.5] (цепочка 1:1 = 1.0) |
